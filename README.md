# MIRA Mind — «نفهم مشاعرهم.. لنبني عالمهم» 🌱

**المساعد الذكي للملاحظة والدعم التربوي** — يوميّة نمو تأملية للأهالي والمربين (أعمار 1–7 سنوات)، تحوّل التدوين اليومي وصور الرسومات إلى **تقرير أسبوعي استرشادي** و**نصائح تربوية إيجابية** — مع هندسة خصوصية صارمة: **كل البيانات تبقى على جهازك**.

> بدأ المشروع بفكرة «MIRA AI / KidSense»، وقد بُني بنسخة **علمية صادقة**:
> لا ادعاء قراءة المشاعر المخفية، لا تحليل تعابير الوجه، لا تشخيص — بل
> **ملاحظة موضوعية + تأمل + نمط عبر الزمن**، وهو ما الذي يفيد فعلاً الأهالي والمختصين.

## 🚫 لماذا لا نحلّل تعابير الوجه أو «رسومات مخفية»؟ (قراءة علمية)

قراءة المشاعر من تعابير الوجه **غير موثوقة علمياً** (خاصة عند الصغار وذوي التنوع العصبي)،
و«فك رموز الرسومات» كحقائق نفسية ضعيف الدلالة وقد يؤذي الأسرة بتصنيفات خاطئة.
MIRA Mind بدلاً من ذلك يمنح الأهالي ما ينفع فعلاً: **سجل منظم + قياسات موضوعية
+ أسئلة ملاحظة** يجلبها الأب/الأم أنفسهم عبر الزمن، فيلّاحظون النمط الحقيقي.

> ⚠️ **تنبيه واضح في كل تقرير:** هذه أداة استرشادية تعليمية — لا تشخيص ولا بديل عن
> مختص. عند أي قلق دائم راجع أخصائياً نفسياً أو طبيباً أطفال.

## 🚀 التشغيل (5 دقائق)

```bash
# 0) متطلبات: Python 3.8+ و  Pillow اختياري (لقياسات الرسم)
pip3 install pillow

# 1) التوكن من @BotFather في .env (لا يُنشر أبداً)
cp .env.example .env    # ثم املأ MIRA_BOT_TOKEN

# 2) فحص ذاتي
python3 selftest.py

# 3) شغل البوت
python3 bot.py

# أو من سطر الأوامر بدون تيليجرام
python3 cli.py register 100 "لينا" 36
python3 cli.py log 100 --mood سعيد --energy 4 --acts مكعبات، تلوين
python3 cli.py drawing 100 ./drawing.png --mood فضولي
python3 cli.py report 100
```

**السرد الدافئ الاختياري:** ثبّت [Ollama](https://ollama.com) ثم `ollama pull gemma4:12b`
(أي نموذج محلي، غيّر `MIRA_MODEL`) — بدون هذا الخيار يعمل كل شيء تماماً.
